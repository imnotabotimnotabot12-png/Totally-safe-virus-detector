# Totally-safe-virus-detector

a virus detector (TOTALLY SAFE) built with **AutoHotkey v2**.

## Key Features
* **VirusTotal API Telemetry:** Real-time global threat checks via MD5, SHA-1, and SHA-256 hashes.
* **Direct Hash Lookup:** Query raw SHA-256 signatures directly without local file payloads.
* **Header & Magic Bytes Inspection:** Detects file extension spoofing (e.g. `.exe` disguised as `.png`).
* **Algorithmic Trust Scoring:** Granular 0%–100% safety evaluation engine.
* **Full SOC Audit Telemetry:** Exportable comprehensive forensic reports.

## 📋 Requirements
* Windows 10 / 11
* [AutoHotkey v2.0+](https://www.autohotkey.com/)

## 🛠️ Usage
1. Download `advanced_scanner.ahk`.
2. Double-click to run with AutoHotkey v2.
3. Drag and drop any file or paste a SHA-256 hash to analyze!
